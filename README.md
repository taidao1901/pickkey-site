# pickkey-site

Public pages required by the TikTok app review for **Pick Key**:
`index.html` (app / website URL), `terms.html`, `privacy.html`, `oauth.html` (OAuth redirect target that
displays the authorization code for the operator to paste into the setup command).

Served by GitHub Pages. Pick Key itself is a private tool that runs on the channel owner's computer;
nothing here runs server-side.
